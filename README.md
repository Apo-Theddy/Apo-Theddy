## Featured: [Godesk](https://godesk.goruts.com)

An infinite canvas of real terminals where coding agents (Claude Code, Codex, OpenCode) work side by side and coordinate with each other.

- Real shells in pseudoterminals on a zoomable canvas, with workspaces that keep processes running
- Automatic links between terminals, plus a `godesk list / send / read` CLI so agents can talk to each other
- Built with Rust (Tauri 2), React, TypeScript and xterm.js, released for Windows and Linux

[Website](https://godesk.goruts.com) · [Download v0.1.0](https://github.com/Goruts/godesk/releases/tag/v0.1.0) · [Source](https://github.com/Goruts/godesk)
